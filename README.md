# Linqis

Every meeting, decoded.

AI-powered meeting summarizer that generates transcripts, executive summaries, action items, and decisions from any meeting recording.

## Tech Stack

- **Frontend**: Next.js 16, TypeScript, Tailwind, Radix UI
- **Backend**: Node.js + Express
- **AI**: Whisper API (transcription), Gemini + Groq (analysis)
- **DB**: PostgreSQL + Prisma
- **Queue**: BullMQ + Redis
- **Auth**: Google OAuth + NextAuth
- **Deploy**: Vercel (frontend) + Railway (backend)
